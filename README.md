# 044252 — מעקב שאלות עבר לפי נושאים

מטריצת מעקב לשאלות של מבחני העבר בקורס **מערכות ספרתיות ומבנה המחשב (044252)**, הטכניון.
כל שאלה ממופה לנושא מהסילבוס ולמועד שבו הופיעה, עם ניקוד, סוג (אמריקאית/פתוחה),
דירוג קושי, ומספר העמוד בקובץ המבחנים.

**האתר:** `index.html` — עמוד בודד, ללא תלויות חיצוניות. סימון "נפתר" נשמר ב-localStorage של הדפדפן.

מבחני 2018 מחולקים לשני חלקים לכל מועד, כפי שהם בקובץ המקור, ולשאלות של
מועד א׳ חלק 1 לא מופיע ניקוד במקור.

## תצוגות

- **מחשב** — מטריצה: נושאי הסילבוס בשורות, מועדי הבחינה בעמודות.
- **טלפון** (מתחת ל-760px) — רשימה מקובצת לפי נושא, המועדים החדשים ראשונים,
  עם כותרות נושא דביקות וראש דף מקוצר. אותה שאלה מסומנת בשתי התצוגות.
  כפתור `תצוגת טבלה` מחזיר את המטריצה גם בטלפון (עם גלילה אופקית), והבחירה נשמרת.
- **מצב תצוגה** — בהיר כברירת מחדל, כפתור למצב כהה, הבחירה נשמרת.
- **ייצוא/ייבוא** — כפתור `ייצוא התקדמות` מוריד JSON עם הסימונים,
  `ייבוא` טוען אותו חזרה (עם בחירה בין מיזוג להחלפה). כך מעבירים התקדמות
  בין מחשב לטלפון, כי הסימונים נשמרים ב-localStorage לפי דפדפן.

## מבנה

```
index.html            האתר הבנוי — אל תערכו ידנית, הוא נוצר מחדש בכל build
data/questions.json   מקור האמת: מועדים + שאלות
tools/template.html   התבנית (HTML/CSS/JS) עם מקומות להזרקת הנתונים
tools/build.js        build: questions.json + template.html  ->  index.html
tools/add.js          עזר להוספת מועד ושאלותיו
tools/dig.js          חילוץ שאלות מטקסט של PDF (עמודים תקינים)
tools/dig3.js         אותו דבר לעמודים שחולצו בסדר תווים הפוך
tools/extract.py      חילוץ הטקסט מה-PDF (pypdf)
tools/fixrev.py       תיקון עמודים שחולצו הפוך
update.sh             build + commit + push
```

## עדכון

```bash
# 1. עורכים data/questions.json (או מוסיפים דרך tools/add.js)
# 2. בונים ודוחפים
./update.sh "הוספת מועדי 2020"
```

לבנייה בלבד, בלי git:

```bash
node tools/build.js
```

## סכימת הנתונים

```jsonc
{
  "exams": [
    { "id": "w26a", "sem": "חורף תשפ״ו", "moed": "מועד א׳",
      "date": "12.02.2026", "order": "2026-02-12" }   // order קובע את סדר העמודות
  ],
  "questions": [
    { "exam": "w26a", "n": 1,          // מזהה המועד + מספר השאלה
      "topic": "sv",                   // מזהה נושא (ראו TOPICS ב-template.html)
      "pts": 5, "kind": "mc",          // "mc" אמריקאית | "open" פתוחה
      "level": 3,                      // קושי 1–5
      "page": 1355,                    // עמוד בקובץ ה-PDF
      "desc": "…",                     // מה השאלה שואלת, בשורה אחת
      "also": ["fsm"] }                // נושאים משניים (אופציונלי)
  ]
}
```

הנושאים והאשכולות (Arch / Comb / Seq / µArch) מוגדרים במערכי `BANDS` ו-`TOPICS`
בראש ה-script שב-`tools/template.html`.

## הערות על המקור

- **קובץ המבחנים עצמו לא נמצא ב-repo** (מסונן ב-`.gitignore`). מספרי העמודים
  מפנים ל-`All Past Exams 2018-2026.pdf`, שצריך להיות בתיקייה מקומית.
- **תאריכי הכותרות בקובץ לא תמיד אמינים.** למשל עמ' 1044 מסומן "חורף תשפ״ג מועד א׳"
  אבל התאריך הוא 3.8.2023, כלומר אביב. הסיווג כאן הולך לפי התאריכים.
- **עמ' 1161–1184** נושא כותרת זהה למועד ב׳ של חורף תשפ״ד (28.5.2024) אבל השאלות
  שונות לגמרי. הוא מופיע כ"חורף תשפ״ד — טופס נוסף" עד שיתברר מה הוא.
